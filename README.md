# Nebula Forge

SwiftUI idle/merge game. Built without a local Mac — the Xcode project is generated by
[XcodeGen](https://github.com/yonaskolb/XcodeGen) from `project.yml`, and compiled in CI on a
macOS GitHub Actions runner.

## What's here

- `Sources/NebulaForgeApp.swift` — the full app (privacy/ATT gating, Game Center, StoreKit IAP,
  Core Data + CloudKit persistence, and the merge-board/galaxy-grid/prestige/shop game itself).
- `NebulaForge.xcdatamodeld/` — Core Data schema for `CelestialItemEntity` (hand-authored; the
  original code referenced this type without a schema file, which would not have compiled).
- `Sources/NebulaForge.entitlements` — iCloud/CloudKit capability.
- `Sources/PrivacyInfo.xcprivacy` — Apple's required privacy manifest.
- `project.yml` — XcodeGen spec; generates `NebulaForge.xcodeproj` (gitignored, regenerated
  every build so it can never go stale or get corrupted by hand edits).
- `.github/workflows/ios-build.yml` — CI job that installs XcodeGen, generates the project, and
  does an **unsigned** build for the iOS Simulator on every push. This only proves the code
  compiles — it does not sign, archive, or upload anywhere yet.

## Before this can run on your iPhone or ship to TestFlight

1. **Bundle ID**: `com.nebulaforge.nebulaforge` in `project.yml` is a placeholder. Pick a real
   one (e.g. `com.<yourname>.nebulaforge`) and register it as an App ID in your Apple Developer
   account, with the Game Center, iCloud, and In-App Purchase capabilities enabled.
2. **iCloud container**: `iCloud.com.nebulaforge.nebulaforge` (in the entitlements file and in
   `PersistenceController`) needs to match a CloudKit container you create for that App ID.
3. **App Store Connect**:
   - Create the app record with the real bundle ID.
   - Create 5 in-app purchase products matching the IDs in `IAPManager.productIDs`
     (`nebulaforge.starterpack`, `nebulaforge.architectkit`, `nebulaforge.pileofgems`,
     `nebulaforge.nebulapass.monthly`, `nebulaforge.gemsubscription.weekly`) — StoreKit won't
     load products that don't exist there.
   - Create 2 Game Center leaderboards matching `nebulaforge.totalstarlight` and
     `nebulaforge.prestige`.
4. **Signing + TestFlight upload**: needs a second CI job using an App Store Connect API key
   (stored as a GitHub secret) to sign and upload the archive — no Mac required, but this hasn't
   been set up yet since it depends on steps 1-3 existing first.
5. **ATT/tracking decision**: the app currently prompts for tracking permission but has no ad
   SDK wired in. Either integrate one (e.g. Apple's own Advertising network) or drop the ATT
   prompt — asking for a permission you don't use is a common App Review rejection reason.

## Local iteration without Xcode

Push to `main` (or open a PR) and check the Actions tab — the unsigned build tells you within a
few minutes whether the code compiles, without needing a Mac at all.
